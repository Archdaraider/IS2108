┌───────────────────────────────────────────────────────────────────────────┐
│ HOW IT WORKS                                                              │
└───────────────────────────────────────────────────────────────────────────┘

CUSTOMER FLOW:
1. Add products to cart
2. Go to checkout
3. Select payment method:
   • Credit/Debit Card
   • PayNow
4. Select delivery speed:
   • Standard Shipping (FREE)
   • Express Shipping (+$4.99)
   • Overnight Shipping (+$12.99)
5. Fill shipping address
6. Click "Place Order"
   → Order created with payment_method & delivery_time saved! ✅

ADMIN FLOW:
1. Go to adminpanel/orders/
2. See all orders with:
   • Payment method (Card icon or PayNow icon)
   • Delivery speed (Standard/Express/Overnight icon)
3. Click on order to view details
4. See Payment & Delivery info in summary
5. Edit fields if needed and save
